# Mazcufit image assets

Place the official Mazcufit logo in this folder with the exact filename:

```text
img/logo.png
```

The HTML templates already reference that path with:

```html
<img src="img/logo.png" alt="Logo Mazcufit" class="logo-mazcufit" />
```

No generated or placeholder logo file is committed, so the final brand image can be added manually without changing the HTML.
